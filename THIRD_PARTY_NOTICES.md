# Third-party dependencies

Dependencies retain their own notices. This inventory grants no license to HomeFace
Guard's original code and does not resolve its provenance.

- Flask: BSD-3-Clause; upstream `pallets/flask` LICENSE.txt.
- Flask-Limiter: MIT; upstream `alisaifee/flask-limiter` LICENSE.txt.
- NumPy: BSD-3-Clause plus bundled dependency notices in the installed distribution.
- OpenCV Python/contrib: wheel wrapper, OpenCV, Haar data and bundled dependencies
  retain notices included in the installed wheel's distribution metadata.
- Pillow: HPND plus bundled dependency notices in the installed distribution.
- Waitress: ZPL-2.1; upstream `Pylons/waitress` LICENSE.txt.
- Tailwind CSS: MIT. Generated CSS includes its upstream notice. Its complete license
  is preserved in `third_party/TAILWIND_LICENSE.txt` for the generated stylesheet.

Retain transitive notices when redistributing environments, wheels or binaries.
Packages are installed, not vendored here. Development tools have separate licenses.
